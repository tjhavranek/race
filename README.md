# Litomyšl Racing Game
 
A browser racing game set in Litomyšl, Czech Republic. Built by kids (ages 8–12) using [Claude Code](https://docs.anthropic.com/en/docs/claude-code) in about two hours (and then many more hours testing and improving ;).
 
## [▶ Play now](https://tjhavranek.github.io/race/)
 
No install needed — runs in your browser. Works on desktop and mobile.
 
## The story
 
Our kids were sick and bored at home, so we introduced them to Claude Code. They did almost everything themselves — designing the track, setting the rules, picking the features. We only helped with publishing it on GitHub.
 
The graphics are charmingly 1980s. But it runs smoothly and it's fun.
 
## Features
 
- Racing through the streets of Litomyšl
- Fullscreen mode
- Music toggle
- Lap time tracking (min / avg / max)
 
## Takeaway
 
If you're a researcher or professional who hasn't tried AI-assisted coding yet, it's worth setting aside an hour to play with these tools. If our kids can build a working game in two hours, you might be surprised what you can do.
